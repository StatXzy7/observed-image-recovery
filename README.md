# observed-image-recovery

A small Linux/CPU grayscale inverse-problem solver that alternates an
observation-residual gradient step with an approximate projection onto the
range of a small generator. Implemented with **NumPy + Pillow only**; no
pretrained weights are loaded.

## Method

Observations are

```
y = mask ⊙ blur(x)        (small kernel, zero-filled boundaries)
```

and the generator is a configuration-driven two-layer tanh network

```
h = tanh(z W1 + b1)
g = tanh(h W2 + b2)       reshaped to the image
```

Each outer iteration performs:

1. **Pixel-space residual step** — descend `0.5 ||H(x) - y||²` using the exact
   adjoint of the observation operator.
2. **Generator-range projection** — a layer-wise block-coordinate inner solve
   over the latent code `z`, hidden activations `h`, and an image-domain
   sparse offset `s`, minimising

   ```
   0.5 ||H(g + s) - y||² + 0.5 β ||h - tanh(zW1+b1)||² + λ ||s||₁
   ```

   The target measures distance **after applying the observation operator**
   (not plain pixel distance). The L1 offset is handled by a soft-threshold
   proximal step; `λ = 0` disables the constraint completely. The inner loop
   is bounded by `inner_max_iter` and stops on a relative tolerance.

Images use the internal scale `[-1, 1]` (0 maps to mid-gray).

## Statuses

- `converged` — outer residual reached `outer_tol` within the iteration budget.
- `iterations_exhausted` — budget used up; a finite result is still returned
  and the message says whether the inner projection reached its tolerance.
- `unobservable` — every pixel is missing; the problem is unconstrained.
- Non-finite inputs, shape mismatches and illegal step sizes raise
  `ValueError`.

## Install

```bash
pip install -r requirements.txt
```

## Run

```bash
# model-consistent demo (ground truth generated by the configured network)
python3 -m geninv --solvable --height 12 --width 12 --missing 0.35 --out-dir outputs

# generic fixed-seed synthetic image with a fresh untrained generator
python3 -m geninv --height 12 --width 12 --missing 0.35 --out-dir outputs
```

Outputs in `--out-dir`:

- `observation.png` — observed pixels (missing pixels are black).
- `reconstruction.png` — reconstructed image (uncropped).
- `difference.png` — full uncropped error map with the center crop marked by
  a yellow rectangle, plus the zoomed crop itself.
- `report.json` — parseable per-iteration and summary metrics. Every metric
  uses uncropped values.

Key options: `--pixel-step`, `--sparse-penalty`, `--inner-tol`,
`--inner-max-iter`, `--outer-tol`, `--outer-max-iter`, `--seed`.

## Package layout

- `geninv/operators.py` — zero-padded blur, its adjoint, and masked `H`/`Hᵀ`.
- `geninv/generator.py` — two-layer tanh forward map from `GeneratorConfig`.
- `geninv/synthetic.py` — fixed-seed images, masks, kernels, sample problems.
- `geninv/projection.py` — observed-domain layer-wise inner projection.
- `geninv/solver.py` — alternating outer loop, validation, status, records.
- `geninv/report.py` — PNG/JSON exporters.

## Tests

```bash
python3 -m unittest discover -s tests -v
```

The suite (29 tests) checks:

- blur/observation **adjoint consistency** by random inner products;
- pixel and generator **gradients against finite differences**;
- residual improvement on a fixed, model-consistent sample;
- that the L1 penalty shrinks the offset and `λ = 0` disables it;
- tolerance stopping, budget exhaustion, the all-missing unobservable state,
  non-finite/shape/step-size rejection, and finite results when the inner
  loop cannot converge;
- exported PNGs at the **actual decoded pixel level** (not file existence).
